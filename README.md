# 旅行助手应用

这是一个基于React和TypeScript的旅行规划与记录应用。

## 功能

- 旅行规划
- 旅行记录
- 个人中心

## 如何运行

### 安装依赖

```bash
npm install
```

或者使用yarn:

```bash
yarn install
```

### 启动开发服务器

```bash
npm start
```

或者使用yarn:

```bash
yarn start
```

应用将在 http://localhost:3000 启动。

## 项目结构

- `/src`: 源代码目录
  - `/components`: React组件
  - `App.tsx`: 主应用组件
  - `index.tsx`: 应用入口点
- `/public`: 静态资源目录

## 技术栈

- React
- TypeScript
- Lucide React (图标库)
